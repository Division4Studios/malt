# MALT — Multi-Agent Local Team

![MALT — local agents, shared intent, verified delivery](https://raw.githubusercontent.com/Division4Studios/malt/main/docs/assets/malt-social.svg)

**Local agents. Shared intent. Verified delivery.**

MALT turns the Claude Code, Codex and GitHub Copilot CLIs you already subscribe to into a coordinated delivery team on your own machine. A product owner and a team lead plan your objective into small deliveries, developers work in owned Git worktrees, two independent reviewers check each change, and MALT merges only the exact reviewed commit before verifying main. You steer it from a local, installable web console.
